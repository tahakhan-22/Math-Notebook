# IPAD MATH NOTE

A touch-first mathematical notebook for mobile, tablet, and iPad users, powered by Gemini API, SymPy, and React Canvas.

## Project Structure
- **`Frontend/`**: React, Vite, Tailwind CSS, Mantine, MathJax, Touch Canvas, Theme Engine.
- **`Backend/`**: FastAPI, Gemini API Vision & Tutor Pipeline, Deterministic SymPy Solver.

## Development
- Frontend: `cd Frontend && npm run dev`
- Backend: `cd Backend && python main.py`
