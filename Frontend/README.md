# IPAD MATH NOTE — React Canvas Frontend

## Overview
Touch-first digital mathematical notebook built with React, Vite, Tailwind CSS, Mantine, and MathJax.

## Features
- **Touch-First Notebook Canvas**: High-DPI canvas with vector stroke tracking, pointer capture, and color/stroke controls.
- **Contextual Action Bar**: Floating toolbar appearing above selected expression cards (`Solve`, `Explain`, `Hint`, `Verify`, `Visualize`, `Alt`).
- **Advanced Cartesian Graphing (`VisualizationViewer`)**: Multi-curve plotting ($f(x)$ AND $f'(x)$), Cartesian axis numbers, grid lines, solution annotations, and touch controls.
- **Persistent ChatGPT-Style AI Tutor History (`chatHistory.ts`)**: Supports multiple conversation sessions saved in `localStorage`, **+ New Chat**, and intelligent short title generation.

## Development
```bash
npm run dev
npm run build
```
